# البرمجة من الصفر — على برنامجك إنت

الملف ده لواحد عمره ما كتب كود. مفيش فيه مصطلح من غير شرح، وكل مثال من برنامج MK-Tech نفسه.

**الأول، إجابة سؤالك:** مش محتاج تفهم الـ ٤١ ألف سطر. محدش بيفهم برنامج سطر سطر، حتى المبرمجين. اللي محتاجه:

1. تفهم **٧ أفكار أساسية** (تحت). دول كل البرمجة تقريبًا.
2. تفهم **خريطة البرنامج**: كل جزء بيعمل إيه.
3. تقرا **٤ ملفات صغيرة** (٢٨٠ سطر) فيهم كل حساب الفلوس.

بعد كده أي ملف تاني هتفتحه هتلاقيه نفس الأفكار السبعة متكررة.

---

## ١. يعني إيه برنامج؟

البرنامج **تعليمات مكتوبة** للكمبيوتر، بيمشي عليها سطر ورا سطر، زي ورقة تعليمات لعامل جديد:

> «لو السواق اشتغل اليوم، احسبله اليومية. لو اشتغل أكتر من ٨ ساعات، زوّد الأوفر.»

الكمبيوتر مبيفهمش عربي، فبنكتب التعليمات دي بلغة اسمها **TypeScript**. نفس الجملة فوق بتتكتب كده:

```ts
if (worked) {
  pay = dayRate;
  if (hours > 8) pay = pay + (hours - 8) * overtimeRate;
}
```

ده كل الموضوع. الباقي تفاصيل.

## ٢. الأفكار السبعة

### الفكرة ١: المتغير — «علبة عليها اسم»

```ts
const dayRate = 1000;
```

معناها: اعمل علبة اسمها `dayRate` وحط فيها ١٠٠٠. بعد كده كل ما أكتب `dayRate` الكمبيوتر بيفهم ١٠٠٠.

- `const` = العلبة دي قيمتها مش هتتغير.
- `let` = العلبة دي ممكن أغيّر اللي فيها بعدين.

### الفكرة ٢: الأنواع — «إيه اللي ينفع يتحط في العلبة»

| النوع | مثال | معناه |
|---|---|---|
| `number` | `1000` | رقم |
| `string` | `"أحمد"` | نص (دايمًا بين علامتين `" "`) |
| `boolean` | `true` / `false` | صح أو غلط |
| `null` | `null` | فاضي، مفيش قيمة |

```ts
const name: string = "أحمد";
```

`: string` معناها «العلبة دي للنصوص بس». لو حاولت تحط فيها رقم، TypeScript يرفض **قبل** ما البرنامج يشتغل. دي أكبر فايدة ليه: بيمسك الغلط بدري.

### الفكرة ٣: الشرط — «لو ... وإلا ...»

```ts
if (remaining > 0) {
  color = "أحمر";
} else {
  color = "أخضر";
}
```

لو الباقي أكبر من صفر لوّنه أحمر، وإلا أخضر. ده اللي بيلوّن «الباقي له» في البرنامج.

فيه اختصار بتشوفه كتير، نفس المعنى في سطر واحد:

```ts
const color = remaining > 0 ? "أحمر" : "أخضر";
```

اقراها: «الباقي أكبر من صفر **؟** أحمر **وإلا** أخضر».

### الفكرة ٤: الدالة — «ماكينة: تدخّل حاجة تطلّع حاجة»

```ts
function overtimePay(hours: number, rate: number) {
  return hours * rate;
}
```

- `function` = بعرّف ماكينة.
- `overtimePay` = اسمها.
- `(hours, rate)` = اللي بيدخل فيها.
- `return` = اللي بيطلع منها.

واستخدامها:

```ts
const pay = overtimePay(3, 40);   // pay = 120
```

البرنامج كله عبارة عن دوال بتنده على دوال. الدالة بتتكتب مرة وتتستخدم ألف مرة.

فيه شكل تاني لنفس الدالة بتشوفه كتير (اسمه «دالة سهم»):

```ts
const overtimePay = (hours: number, rate: number) => hours * rate;
```

### الفكرة ٥: القايمة — «حاجات كتير ورا بعض»

```ts
const days = [1000, 1000, 1250];
```

قايمة فيها ٣ أرقام (٣ أيام شغل). وأهم ٣ حاجات بتتعمل على القوايم:

```ts
days.filter((d) => d > 1000)        // فلترة: هات الأيام اللي أكتر من ١٠٠٠ ← [1250]
days.map((d) => d * 2)              // تحويل: ضاعف كل يوم ← [2000, 2000, 2500]
days.reduce((sum, d) => sum + d, 0) // تجميع: اجمعهم كلهم ← 3250
```

لما تشوف `.filter` اقراها «هات اللي ...»، و`.map` «حوّل كل واحد لـ ...»، و`.reduce` «اجمعهم».

### الفكرة ٦: الكائن — «كارت فيه بيانات حاجة واحدة»

```ts
const driver = { name: "أحمد", dayRate: 300, days: 25 };
```

كارت السواق: اسمه، يوميته، أيامه. وتوصل لأي خانة بالنقطة:

```ts
driver.name        // "أحمد"
driver.dayRate * driver.days   // 7500
```

كل صف في قاعدة البيانات بيتقرا في البرنامج ككارت زي ده.

### الفكرة ٧: الاستيراد — «هات الدالة دي من الملف التاني»

```ts
import { percent } from "./money";
```

معناها: الدالة `percent` مكتوبة في ملف `money.ts`، هاتها أستخدمها هنا. عشان كده البرنامج متقسم ملفات: كل ملف فيه دوال موضوع واحد، والملفات بتستلف من بعض.

والعكس: `export` قدام دالة معناها «الدالة دي متاحة للملفات التانية».

## ٣. رموز هتشوفها كتير

| الرمز | معناه |
|---|---|
| `//` | تعليق: كلام للبني آدم، الكمبيوتر بيتجاهله |
| `=` | حط القيمة في العلبة |
| `===` | هل الاتنين متساويين؟ |
| `!==` | هل مختلفين؟ |
| `&&` | «و» (الشرطين لازم يتحققوا) |
| `\|\|` | «أو» |
| `!` | «مش» (عكس) |
| `??` | «لو فاضي استخدم ده بداله»: `phone ?? "مفيش"` |
| `?.` | «لو موجود هات منه»: `driver?.name` |
| `` `...${x}...` `` | نص جواه قيمة: `` `باقي له ${amount}` `` |
| `{ }` | بداية ونهاية مجموعة تعليمات (أو كارت بيانات) |
| `[ ]` | قايمة |
| `;` | نهاية السطر |

## ٤. قاعدة البيانات — «دفتر فيه جداول»

البرنامج لازم يحفظ الداتا في مكان يفضل موجود بعد ما تقفله. المكان ده اسمه **قاعدة بيانات**، وهي عبارة عن جداول زي الإكسل:

**جدول `drivers`**

| id | name | rate_pt | supplier_id |
|---|---|---|---|
| 1 | أحمد | 30000 | 5 |
| 2 | سيد | 25000 | 5 |

- كل **سطر** = سواق.
- كل **عمود** = معلومة عنه.
- `id` = رقم السطر (مبيتكررش).
- `supplier_id = 5` = «صاحب المعدة بتاعه هو السطر رقم ٥ في جدول أصحاب المعدات». كده الجداول بتتربط ببعض.

والبرنامج بيكلم القاعدة بلغة اسمها **SQL**، قريبة من الإنجليزي:

```sql
SELECT name FROM drivers WHERE supplier_id = 5
```

«هات الاسم، من جدول السواقين، اللي صاحب المعدة بتاعهم رقم ٥.»

```sql
INSERT INTO drivers (name, rate_pt) VALUES ('حسن', 28000)
```

«ضيف سطر جديد في السواقين.»

**ملحوظة:** الفلوس في القاعدة بالقرش مش بالجنيه (`30000` = ٣٠٠ جنيه). عشان الكمبيوتر بيغلط في الكسور، والأرقام الصحيحة مبتغلطش أبدًا.

## ٥. البرنامج متقسم إزاي — «مطعم»

تخيل البرنامج مطعم:

| في المطعم | في البرنامج | المكان |
|---|---|---|
| **الصالة** — اللي الزبون شايفه | الشاشات: الأزرار والجداول | `src/pages/` |
| **الجرسون** — بياخد الطلب ويوديه | الجسر بين الشاشة والحسابات | `src/api/client.ts` |
| **المنيو** — الطلبات المسموحة بس | قايمة بكل العمليات المسموحة | `electron/ipc.ts` |
| **المطبخ** — الشغل الحقيقي | الحسابات وتسجيل الحركات | `core/services/` |
| **الوصفات** — المقادير الثابتة | معادلات الفلوس | `core/calc/` |
| **المخزن** | قاعدة البيانات | `core/schema.ts` |
| **المبنى نفسه** | اللي بيشغّل ده كله على ويندوز | `electron/` (Electron) |

لما تدوس «حفظ دفعة»: الصالة ← الجرسون ← المنيو ← المطبخ ← المخزن، والرد بيرجع نفس الطريق.

**ليه التقسيم ده؟** عشان الزبون ميدخلش المطبخ. الشاشة متقدرش تلمس الداتا مباشرة؛ لازم تعدّي على المنيو، والمنيو بيتأكد إن الطلب مسموح وإن الاشتراك شغال.

## ٦. اقرا أول ملف حقيقي

الملف `core/calc/contractMonth.ts` بيحسب عقد واحد في شهر. خلينا نقراه بالأفكار السبعة:

```ts
import { percent, Piasters } from "./money";
```
**الفكرة ٧:** هات الدالة `percent` من ملف `money`.

```ts
export function contractMonth(i: ContractMonthInput): ContractMonthResult {
```
**الفكرة ٤:** دالة اسمها `contractMonth`. بيدخلها كارت بيانات اسمه `i` (قيمة الشغل، تكلفة صاحب المعدة، النسب)، وبتطلّع كارت نتيجة.

```ts
  const vatPt = i.vatApplies ? percent(i.clientBasePt, i.vatBp) : 0;
```
**الأفكار ١ و٣ و٦:** علبة اسمها `vatPt`. «العميل عليه ضريبة؟ احسب ١٤٪ من قيمة الشغل، وإلا صفر.» و`i.clientBasePt` معناها خانة «قيمة الشغل» من الكارت `i`.

```ts
  const marginPt = i.clientBasePt - i.supplierCostPt;
```
الهامش = اللي على الشركة − اللي لصاحب المعدة.

```ts
  return {
    invoiceTotalPt: i.clientBasePt - whtPt + vatPt,
    netPt: afterTax5Pt - i.contractExpensesPt,
  };
```
**الفكرة ٤ و٦:** رجّع كارت فيه النتيجة: إجمالي الفاتورة = قيمة الشغل − ٣٪ + ١٤٪، والصافي = الهامش بعد الضريبة − المصروفات.

شفت؟ مفيش حاجة برّه السبعة.

**حيلة الأسامي:** أي اسم آخره `Pt` = مبلغ بالقرش. آخره `Bp` = نسبة (١٤٪ بتتكتب 1400). آخره `Id` = رقم سطر في جدول.

## ٧. خطة التعلم

| الأسبوع | تعمل إيه |
|---|---|
| ١ | اقرا الأفكار السبعة فوق مرتين. افتح `core/calc/money.ts` وحاول تقول كل سطر بيعمل إيه |
| ٢ | `core/calc/sarki.ts` ثم `contractMonth.ts` ثم `distribution.ts` |
| ٣ | افتح `core/schema.ts` واقرا أسامي الجداول والأعمدة بس. دي خريطة الداتا كلها |
| ٤ | صفحة واحدة: `src/pages/drivers/Drivers.tsx` مع `core/services/drivers.ts` |

**الطريقة:** افتح الملف، وابعتلي «اشرحلي الملف ده سطر سطر» أو انسخ الجزء اللي مش فاهمه. هشرحه بنفس الأسلوب ده.

**ونصيحة:** كل ملف في `tests/` فيه أمثلة مكتوبة بالعربي: «يومية ١٠٠٠: الشركة تخصم ٣٠ وتزود ١٤٠ وتدفع ١١١٠». دي أسهل طريقة تفهم الدالة بتعمل إيه.

بعد كده الدليل التاني `CODE_GUIDE.md` فيه كل تقنية استخدمناها وخريطة الملفات كاملة.
