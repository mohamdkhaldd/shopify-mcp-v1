معايا مشروع برنامج سطح مكتب (Desktop app) بديل لنظام إكسيل حسابات شركة "البنيان" لتأجير المعدات الثقيلة، شغال أوفلاين بالكامل بقاعدة بيانات SQLite محلية. المشروع مبني بالفعل جزء كبير منه (مراحل ١-٤ من ٦)، والكود موجود في مستودع GitHub `mohamdkhaldd/shopify-mcp-v1` على فرع `claude/heavy-equipment-accounting-app-em2egj` (جوه فولدر `accounting-app/`). لو عندك وصول للمستودع ده اسحب الفرع واشتغل عليه مباشرة. لو مفيش وصول، هرفعلك المشروع كملف مضغوط بديل.

## السياق التجاري
الشركة بتؤجر معدات ثقيلة (مان لفت، بوكيت، ونش) مملوكة لشركاء مستثمرين. بتدير عمليتها من خلال: سائقين بيسجلوا حضور يومي، مقاول (حسن) بيستأجر المعدات ويأجرها هو تاني ياخد كوميشن، موظفين بمرتبات، مقاولين خارجيين بياخدوا دفعات، شركاء بتتوزع عليهم الأرباح بنسب مختلفة لكل معدة، موردين، وخزنة (محفظة/انستا باي/كاش).

## التقنية
Electron + React + TypeScript + Vite + Tailwind CSS + SQLite (better-sqlite3) + Recharts. كود وتعليقات بالإنجليزي، كل حاجة ظاهرة للمستخدم (labels, رسائل) بالعربي مع دعم RTL كامل. خط Cairo محمّل محليًا (offline بالكامل، بدون أي طلب إنترنت وقت التشغيل).

## الشكل (زي Odoo)
Sidebar ثابت يمين (RTL)، انتقال SPA بين الأقسام بدون إعادة تحميل، لون أساسي أخضر #2F8F63 على خلفية فاتحة، كروت بحواف دائرية وظل خفيف (`rounded-card` / `shadow-card` في Tailwind config)، جداول إدخال بيانات حقيقية (مش كروت) للبيانات اليومية.

## الميزة الجوهرية: الإعدادات الديناميكية
صفحة "الإعدادات" فيها إضافة شركاء/سائقين/معدات (مع نسب شركائها)/مقاولين/أنواع مصروفات — وأي حاجة تتضاف هناك تظهر تلقائيًا في كل الشاشات المرتبطة بيها من غير أي بناء يدوي. ده أهم فرق بين البرنامج ده والإكسيل.

## قواعد حسابية مهمة (لازم تتطبق حرفيًا)
- **الأوفر تايم** (يطبّق على السركي، المقاول، ومرتبات الموظفين اليومية): سعر الساعة = اليومية ÷ ٨. ساعات الأوفر تايم = MAX(٠, الساعات الفعلية − الساعات الأساسية). قيمة اليوم = اليومية + (ساعات الأوفر تايم × سعر الساعة).
- **كوميشن حسن** (لكل المعدات ما عدا الونشين): الكوميشن = (يومية المقاول − يومية السركي) + ساعات الأوفر تايم × (يومية المقاول/٨ − يومية السركي/٨)، محسوب من زوج سجلات سركي+مقاول لنفس المعدة ونفس اليوم.
- **استثناء الونشين** ("ونش 5 طن دبوسة" و"ونش 3 وصلة"): الكوميشن = يومية المقاول × ٢٠٪ لو ≤ ٢٥٠٠ج، أو × ١٧.٥٪ لو أكبر.
- **سركي سوق**: يومية ثابتة كاملة بدون ساعات ولا أوفر تايم؛ كوميشن حسن هنا يدوي (مفيش قانون).
- **تنبيه بصري**: لو ساعات السركي والمقاول مختلفة لنفس المعدة/اليوم، يظهر تنبيه أحمر (Badge).

## البيانات الحقيقية المُدخلة كـ Seed
٦ شركاء (الحج رمضان، أبو طارق، أبو أدهم، مصطفى علي، د. حازم، محمد رمضان) بنسبهم الحقيقية في كل معدة، ١٠ معدات، ١٢ سائق/موظف بأجورهم الحقيقية، ٦ مقاولين، ١١ نوع مصروف (من الداتا فاليديشن في شيت المصروفات الأصلي).

## المراحل والحالة الحالية

**تمت (١-٤):**
1. الهيكل العام + Sidebar + صفحة رئيسية (Dashboard) بأرقام حقيقية من الإكسيل الأصلي.
2. صفحة الإعدادات الكاملة + قاعدة بيانات SQLite بكل الجداول (equipment, partners, equipment_partner_shares, employees, contractors, expense_categories, daily_logs, monthly_expenses, employee_advances, hassan_ledger, treasury_accounts, suppliers...).
3. قسم المعدات: صفحة لكل معدة فيها تبويبات — السركي/المقاول/سركي سوق (كل واحد شيت شهري حقيقي: كل يوم في الشهر صف، تتعدل الخلايا وتتحفظ لوحدها onBlur عبر IPC channel اسمه `dailyLogs:upsert` بمفتاح فريد equipment_id+date+role)، المصروفات (مربوطة بطريقة دفع: محفظة/انستا باي/كاش)، والأرباح وتوزيع الشركاء (محسوبة تلقائيًا).
4. الرواتب: كل سائق مرتبه بيتحسب تلقائيًا من مجموع أيامه في السركي عبر كل المعدات، مع سلف (مربوطة بطريقة دفع للخزنة) وشيت مرتب فردي قابل للطباعة. حسن: تبويب كوميشن (محسوب تلقائي بالقوانين فوق + جدول تجميعي لكل معدة/شهر) وتبويب حساب شخصي منفصل (٤ أنواع: سلفة/سداد/مستحق/تحصيل) مع تفصيل بالشخص/الجهة مش إجمالي عام.
   - زرار طباعة على شيت السركي وشيت المرتب: بيخفي كل حاجة تفاعلية (`.no-print` class) ويظهر بس البيانات + توقيع وختم في الآخر (`src/components/PrintSignoff.tsx`).
   - لوجو الشركة موجود في `public/logo.png`، الـ Sidebar بيعرضه تلقائي مع fallback لحرف "ب" لو الملف مش موجود.

**الباقي:**
5. المقاولين والشركاء: لوحة لكل مقاول (جدول توزيع الشغل تلقائي من سجلات السركي/المقاول، سجل دفعات، الباقي = إجمالي شغله − إجمالي المدفوع)، ولوحة لكل شريك (إجمالي المستحق له من كل المعدات، توزيعه، سجل دفعات، الباقي له).
6. الخزنة (٣ حسابات: محفظة/انستا باي/كاش، برصيد يدوي + صافي حركة شهري تلقائي من كل مصادر الدخول/الخروج المسجلة بالفعل)، الموردين (بدون قائمة ثابتة — اسم حر وقت الشراء، داشبورد ديناميكي)، والتقارير النهائية.

## طريقة الشغل
اشتغل مرحلة واحدة في المرة، اعرض خطة مختصرة الأول، ولا تنتقل للمرحلة اللي بعدها غير بعد موافقة صريحة. بعد كل مرحلة، شغّل التطبيق فعليًا وخد لقطات شاشة تثبت إن الحسابات صح قبل ما تعتبر المرحلة خلصت.
