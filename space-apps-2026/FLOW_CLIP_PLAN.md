# Google Flow clip plan (made from the game scripts)

Each line of a briefing = one Flow clip (about 8 seconds; long lines = 2 clips). Upload the character picture as an **Ingredient** for every clip of that character, so the astronaut stays the same.

**Voice:** make the clips with **no dialogue audio** (ambient sound only), then put the voice on top in editing (ElevenLabs, your own recording, or the voice track from the game video). The visor is fully mirrored, so lips never need to match.

**File names when done:** `<mission>_<role>.mp4`, e.g. `storm_science.mp4`. Send them back and they go into the game as-is.
